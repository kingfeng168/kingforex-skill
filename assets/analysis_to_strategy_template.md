# 宏观 → 策略落地模板(三阶闭环 · 含盘面分析)

> **用途**:把"权威宏观研判"经"跨市场验证 + 盘面分析"转化为"**可执行交易策略(文字写明入场区/止损/目标)**"。
> 每一阶都有 **Gate(通过条件)**;不通过则降级或放弃,不得硬做。
> 所有宏观输入必须来自 `references/data_sources.md` 列出的权威渠道,并标注 `[源 | 截至]`。
> 下笔前先读 `references/analysis_framework.md`,建立"宏观定方向、跨市场验方向、盘面定时机"的三维印证框架,再逐阶推进;任一维度反向即降级或放弃。

---

## 第一阶 · 宏观研判(权威数据驱动)

| 项 | 结论 | 来源与截至 |
|----|------|------------|
| 宏观 Regime(四选一) | 增长强+通胀升 / 增长弱+通胀高 / 衰退+通胀落 / 流动性危机 | `[ ]` |
| 美元方向(强/弱/震荡) | | `[ ]` |
| 利率背景(美债/实际利率) | US10Y ___、10Y TIPS ___、盈亏平衡 ___ | `[FRED | ]` |
| 风险偏好(risk-on / off) | VIX ___、标普 ___、信用利差 ___ | `[ ]` |
| 关键预期差线索 | (FedWatch vs 点阵图 / 数据 vs 预期) | `[ ]` |
| 今日高风险事件 | 非农 / CPI / FOMC / PMI / EIA @ 时点 | `[日历 | ]` |

**Gate 1**:宏观方向清晰(至少判定美元偏强/偏弱 + regime),否则进入"只做日内或空仓"降级路径。

---

## 第二阶 · 跨市场验证(≥2 个相关市场确认方向)

| 候选品种 | 验证市场 1 | 验证市场 2 | 是否共振 | 备注 |
|----------|------------|------------|----------|------|
| (如 XAUUSD) | 10Y TIPS | DXY | 是/否 | |
| (如 AUDUSD) | 铜 HG | AUD/JPY | 是/否 | |
| (如 USDCAD) | WTI | 信用利差 | 是/否 | |

**Gate 2**:至少两个相关市场方向与候选方向一致(共振)才进入第三阶;冲突则降仓或放弃该品种。

---

## 第三阶 · 候选筛选(1–3 个高确定性)

| 优先级 | 品种 | 方向 | 宏观逻辑(一句话) |
|--------|------|------|------------------|
| 1 | | | |
| 2 | | | |
| 3 | | | |

**Gate 3**:只保留 1–3 个;美元偏强时剔除逆势做多商品货币的机会。

---

## 第四阶 · 盘面分析

> 宏观对、盘面不对仍不入场。本阶把"方向"落实为"现在能不能做、具体怎么做",**结合 K 线与技术结构判断**。方法见 `references/ta_reading.md`。

| 项 | 内容 |
|----|------|
| 市场结构 | 趋势 / 区间 / 无序震荡(大/小周期方向是否一致) |
| 关键位(精确到价) | 前高前低 / 结构位 / POC / 整数关口 / 均线 |
| K 线信号 | 触发处的形态(锤子 / 吞没 / 十字 / 射击星等) |
| ATR(14) | ___ → 据此定止损距离(不用固定点数) |
| 量价 / 动能 | 是否配合(突破放量、回调缩量、有无背离) |

**Gate 4**:结构清晰、顺宏观方向,且以文字写清入场/止损位,才进入第五阶;逆势或无结构则放弃。

---

## 第五阶 · 具体交易策略(标注入场 / 止损 / 目标点位)

| 字段 | 内容 |
|------|------|
| 品种 | |
| 方向 | 多 / 空 |
| 触发条件 | 突破确认回踩不破 / 限价挂单回调至结构位 |
| 入场区域 | ___ – ___ |
| 止损 | ___ 点(= ATR×倍数,置于结构外);风险金额 ___ |
| 目标 | 前高/前低 / 斐波扩展 / 通道上轨 |
| 仓位 | ___ 手(用 `scripts/position_size.py`,单笔风险 ≤1%) |
| 失效条件 | 宏观反转 / 跨市场背离 / 事件前 |
| 情景预案 | 若 A 发生做多;若 B 发生放弃 |

- 入场/止损/目标必须落在结构合理处;**盈亏比 ≥ 1:1.5(建议 ≥ 1:2)**。
- 订单类型:突破→止损单挂单;回调→限价单挂单。禁止数据前 5 分钟市价单。

---

## 第六阶 · 风险体检(用 `scripts/exposure.py`)

- 单笔风险 ≤ 总资金 1%(回撤后降至 0.5%)。
- 组合总风险暴露 ≤ 总资金 5%。
- 无单一宏观暴露:不得同时多黄金+多澳元+多原油(=单一美元空头)。
- 压力测试:FOMC 意外 / 美股 −5% / 油价 −10% 下最大回撤是否可承受。

**Gate 6**:不通过则削减手数或剔除相关性最高的持仓。

---

## 降级规则(贯穿全程)

| 情形 | 动作 |
|------|------|
| 宏观模糊、Regime 难判 | 只做日内或当日不交易 |
| 跨市场不共振 | 放弃该品种 |
| 盘面结构逆势 / 无结构 | 不入场 |
| 无法以文字写清合理入场/止损位 | 放弃(不凭感觉开仓) |
| 重大事件前(非农/FOMC) | 空仓或减仓,不赌数据 |
| 连续亏损 3 次 | 暂停交易,强制复盘 |
