> 本文档把金融工程 / 量化分析的核心概念，翻译成**手工交易者能直接套用的规则**。每节给公式、解释、用法、陷阱。

## 一、收益与风险度量

### 1.1 对数收益率（Log Return）

**公式**：`r_t = ln(P_t / P_{t-1})`

- 对数收益可加（多期复合直接求和），算术收益不可加；统计建模几乎都用对数收益。
- 小幅波动时 `ln(1+x) ≈ x`，与算术收益差异 < 1%。

**用法**：所有 `quant_metrics.py` 内部指标（Sharpe、VaR、相关等）都基于对数收益。

### 1.2 年化收益与年化波动率

**公式**：
- 年化收益：`R_ann = (Σ r_t) / N × periods_per_year`
- 年化波动率：`σ_ann = σ_daily × √(periods_per_year)`（日线=252，周线=52，小时=2190）

**用法**：跨周期比较策略收益与风险。日线策略的 15% 年化波动率，对应大约 1% 日波动。

### 1.3 Sharpe 比率

**公式**：`S = (R_ann - R_f) / σ_ann`（R_f 为年化无风险利率）

**解读**：
- S < 0：策略跑不赢无风险收益。
- 0 < S < 0.5：低质量。
- 0.5 < S < 1：合格。
- S > 1：优秀（持续难）。
- S > 2：高度怀疑过拟合或回测作弊。

**陷阱**：
- 短样本（< 1 年）Sharpe 极不稳定，至少要 2–3 年才有意义。
- 负偏度的厚尾分布下，Sharpe 会**高估**真实风险收益比。

### 1.4 Sortino 比率

**公式**：`S_sortino = (R_ann - R_f) / σ_downside`，其中 `σ_downside = √(mean(min(0, r_t - r_f)²))`

**优势**：只惩罚下行波动，不惩罚上行波动；对手工趋势/突破策略更公平。

### 1.5 Calmar 比率

**公式**：`Calmar = R_ann / |MaxDrawdown|`

**用法**：直接衡量"收益 vs 最坏回撤"。Calmar > 1 为合格；趋势跟踪策略常见 0.3–0.8。

## 二、波动率建模

### 2.1 简单历史波动率

**公式**：`σ = stdev(r_t)`，年化 = `σ × √(252)`

**弱点**：等权看待所有历史，对近期波动反应慢。

### 2.2 EWMA（指数加权移动平均，RiskMetrics）

**公式**：`σ²_t = λ × σ²_{t-1} + (1-λ) × r²_t`，默认 `λ = 0.94`（日线）

**优势**：近期数据权重大，波动率反应快。J.P. Morgan RiskMetrics 1996 标准。
**用法**：日线 λ=0.94；小时 λ=0.97；日线 λ=0.97 更平滑（适合做止损基准）。

**陷阱**：在低波动期会低估真实风险（突然跳空时 VaR 失效）。

### 2.3 已实现波动率（Realized Volatility，RV）

**公式**：`RV_n = √(Σ r²_i / n)`，n=21（一月）/63（一季）

**用法**：衡量"最近 n 个 bar 的实际波动"；与 EWMA 配合观察 regime 切换。

### 2.4 GARCH(1,1)（进阶参考）

**公式**：`σ²_t = ω + α × r²_{t-1} + β × σ²_{t-1}`，约束 `α + β < 1`

**优势**：波动率聚类（volatility clustering）+ 长期均值回归两个特性都建模。
**说明**：`quant_metrics.py` **不实现 GARCH**（纯标准库约束）；如需 GARCH 拟合请用 `arch` Python 库或 R 的 `rugarch` 包。

**实装示例（Cuthbertson《金融工程》推荐路径）**：

```python
# 安装: pip install arch
import arch
import pandas as pd

rets = pd.Series([...])  # 对数收益率序列
model = arch.arch_model(rets, vol="Garch", p=1, q=1, mean="Constant")
res = model.fit(disp="off")
omega, alpha, beta = res.params["omega"], res.params["alpha[1]"], res.params["beta[1]"]
long_run_vol = (omega / (1 - alpha - beta)) ** 0.5   # 长期无条件波动率
# 用途: 长期波动率做止损基准 / 波动率目标分母; alpha+beta 越接近 1 波动越持久
```

**实战意义**：`α + β`（波动率持久度）越接近 1，波动率冲击衰减越慢 → 止损距离应放宽；`long_run_vol` 是"波动率目标"策略（§5.3）的长期锚。

### 2.5 Regime 切换

当 `RV_21 / RV_252 > 1.5` 时进入**高波动 regime**：
- 止损距离按 `1.5×ATR` 而非 `1.0×ATR` 留；
- 仓位按 `risk_budget × 0.7` 折扣；
- 事件窗口前主动降仓。

## 三、回撤与资金曲线

### 3.1 最大回撤（Max Drawdown, MDD）

**定义**：从历史峰值到随后谷底的最大跌幅。`MDD = min(P_t / max_{s≤t} P_s - 1)`。

**解读**：
- MDD 10%–15%：正常策略；
- MDD 20%–30%：高风险，建议仓位减半；
- MDD > 40%：接近"永久性损失"心理阈值，恢复期通常 1–3 年。

### 3.2 回撤持续期（Drawdown Duration）

**定义**：从峰值到回撤恢复的 bar 数（未恢复则计为当前长度）。

**用法**：评估策略"恢复力"。长期策略的回撤持续期应 < 6 个月（≈ 126 个日 bar）。

### 3.3 回撤阶梯降仓（Drawdown-based Sizing）

| 当前回撤 | 仓位倍数 |
|---|---|
| 0%–5% | 1.0× |
| 5%–10% | 0.8× |
| 10%–15% | 0.6× |
| 15%–20% | 0.4× |
| > 20% | 0.2×（强制冷静期） |

**纪律**：触达 -20% 必须暂停 1 周并复盘；不允许"加仓回本"。

### 3.4 收益回撤比（Return/Drawdown = CAGR / MaxDD）

`CAGR / MaxDD`（亦称**收益回撤比**）是手工交易者最该盯的综合指标：
- < 1：危险（赚的不够补回撤）；
- 1–2：合格；
- 2–5：优秀；
- > 5：注意回测过拟合。

**门槛（Carver《Systematic Trading》口径）**：任何策略上线前收益回撤比必须 ≥ 1，否则"回撤一次吃掉一年利润"，心理与资金双重不可持续。把它与 Sharpe 并列写入每周复盘表。

## 四、VaR 与尾部风险

### 4.1 VaR（Value at Risk）

**定义**：在给定置信水平下，**最坏情况下**的单期损失幅度。
- 95% VaR：最坏 5% 情形下的损失；
- 99% VaR：最坏 1% 情形下的损失。

**两种算法**：
- **历史法**：直接取历史收益分位数（最可靠，推荐）；
- **参数法**：假设正态分布，`VaR = μ - z × σ`（z=1.645 对应 95%，z=2.326 对应 99%）。

**陷阱**：正态假设**严重低估**厚尾真实损失。黄金、原油、外汇突发事件下，真实 99% VaR 经常是参数 VaR 的 2–3 倍。

### 4.2 CVaR / ES（Expected Shortfall）

**定义**：超过 VaR 的尾部**平均损失**（也称 Expected Shortfall, ES）。

**意义**：CVaR > VaR，且对"最坏情形"刻画更准确——VaR 告诉你"最坏可能是 X"，CVaR 告诉你"如果最坏真的发生，平均亏多少"。

**实战**：仓位计算以 CVaR 为锚，而非 VaR；单笔风险 ≤ 账户 × 1% 应在**最坏 1% 情形**下也成立。

### 4.3 厚尾与偏度

- **偏度 < 0**（左偏）：亏损厚尾，金融数据常态；仓位需向 **CVaR 估计**靠拢。
- **峰度 > 0**（尖峰厚尾）：真实分布的标志；正态峰度 = 0。
- **Jarque-Bera 检验**：JB ~ χ²(2)，5% 临界值 5.99；拒绝正态即承认厚尾。

**实战口诀**："参数 VaR 永远低估，外汇/商品至少乘 1.5。" 对应脚本 `quant_metrics.py` 的 VaR/CVaR/JB 输出一并核对。

## 五、仓位管理量化

### 5.1 凯利公式（Kelly Criterion）

**公式**：`f* = (p × b - q) / b`，其中 `p` 胜率，`q = 1-p`，`b` 盈亏比。
**简化版**（已知胜率 W 与 R 倍数期望值）：`f* = W - (1-W)/R`

**实战约束**：
- **永远用分数凯利**（1/4 凯利或 1/2 凯利），全凯利在估计误差下会爆仓；
- 硬封顶 **f ≤ 25%** 单策略；
- 估计 W、R 用**至少 30 笔**样本；
- 样本 < 30 笔前用 1% 固定分数起步。

**手工 vs 凯利**：手工交易者因为滑点、心理损耗、参数估计误差，建议 **1/4 凯利** 甚至更低。

### 5.2 风险预算法（Risk Budgeting）

总账户风险预算 = 单笔风险 × 持仓数 × 相关性折扣

**经验公式**：
```
账户总风险预算 = 3%–5% × Equity
单笔风险 = 总预算 / (持仓数 × 最大相关性折扣)
```
相关性折扣：完全独立的 3 笔单子 = 1×；两笔高度相关（如多黄金+多白银）≈ 1.5×；两笔完全相反对冲 ≈ 0.5×。

### 5.3 波动率目标（Vol Targeting）

**公式**：`f_t = (σ_target / σ_realized) × f_max`

**用法**：
- `σ_target` = 账户月度目标波动率（建议 5%–10%）；
- `σ_realized` = 策略 21 日已实现波动率；
- 高波动期自动减仓，低波动期自动加仓。

**优势**：把"风险"标准化为"账户波动率"，跨品种、跨策略可比。

### 5.4 R 倍数与期望值

**R = 盈亏 / 单笔初始风险**（R=2 意味着赚 2 倍单笔风险）
**期望值 EV = W × avg_win_R - (1-W) × 1**

**门槛**：EV > 0 才有正期望值；EV > 0.2R 是合格系统；EV < 0.1R 长期会被佣金+滑点吃掉。

**实战**：周复盘统计近 30–50 笔的 W 和 avg_win_R，估算 EV，低于 0.1R 立即降仓或停策略。

### 5.5 最优 f（Optimal f，Ralph Vince）

**与凯利的区别**：凯利 `f* = p - (1-p)/b` 假设收益服从特定分布；**最优 f** 直接用历史逐笔盈亏序列数值搜索，不依赖分布假设，更能反映厚尾真实风险。

**公式**：
- `W = |最大单笔亏损|`
- 每笔持有期收益 `HPR_i(f) = 1 + f × (P_i / W)`
- 期末财富倍数 `TWR(f) = ∏ HPR_i(f)`
- 几何增长率 `G(f) = TWR(f)^(1/N)`，**f* = argmax G(f)**

**关键结论（Vince 原书反复强调）**：
- 全 f（f*）几何增长率最大，但回撤/破产风险极高——实测常 > 99% 腰斩概率；
- **分数 f（1/4、1/2）** 才是可执行仓位；1/4 f 通常把破产概率压到 < 5%；
- f 是"每笔最大亏损占权益比例"的倒数尺度，本质上 = 单笔风险预算。

**脚本**：`scripts/optimal_f.py` —— 网格搜索最优 f + 蒙特卡洛重采样，输出 f*、分数 f、回撤分布（平均/中位/P95/P99/最坏）与破产概率。

**用法**：
```bash
python scripts/optimal_f.py --csv "D:/workbuddy/输出文件/trades_pnl.csv" --mc 10000
python scripts/optimal_f.py --csv trades.csv --json   # 结构化输出
```

**陷阱**：最优 f 对历史序列极敏感（一笔极端亏损就大幅改写 f*），**必须配 1/4 分数 f + 蒙特卡洛回撤核验**；样本 < 30 笔时 f* 不可靠，退回 1% 固定分数。

### 5.6 区间市 vs 单边市的仓位管理（魏强斌《外汇交易进阶》）

**核心**：仓位策略必须随市场结构切换，而非固定不变：

| 市场结构 | 仓位方向 | 逻辑 |
|---|---|---|
| **区间市（震荡）** | 顺向减仓、接近边缘减仓 | 假突破多、利润空间有限，重仓易被扫 |
| **单边市（趋势）** | 顺向加仓、突破确认加仓 | 趋势延续概率高，让利润奔跑 |
| **无序震荡** | 空仓或极轻仓 | 胜率与盈亏比双低，无交易价值 |

**与 v1.3.0 三维印证衔接**：先由 Hurst 指数（§8）+ 多周期共振（盘面）判定"区间 or 单边"，再套用上表决定加减仓方向；区间市配合 Z-score 反转（§8.3），单边市配合趋势跟踪（H>0.55）。

## 六、因子模型（FX / 商品）

### 6.1 FX 三因子（carry / momentum / value）

| 因子 | 度量 | 信号方向 |
|---|---|---|
| **Carry** | 利差 - 远期点 | 套息货币多、空高息货币空 |
| **Momentum** | 过去 1/3/6/12 月收益 | 顺势 |
| **Value** | 实际有效汇率 vs 长期均值 | 偏离反转（慢变量） |

**手工落地**：
- Carry 因子：直接读 BIS 政策利率差 + 1Y 远期点（World Bank / live_market_fetch）。
- Momentum 因子：用 60 日/120 日/252 日对数收益加权。
- Value 因子：用 IMF REER（实际有效汇率）相对 5 年均值的 Z-score。

### 6.2 商品期限结构因子（Term Structure）

**contango**：远月 > 近月 → 持仓成本（Carry 负） → 通常看空
**backwardation**：远月 < 近月 → 现货紧张（Carry 正） → 通常看多

**公式**：`roll yield = (P_near - P_far) / P_near × (365 / days_to_near_expiry)`

**用法**：原油 WTI 持续 backwardation → 现货吃紧，配合 EIA 库存下降 → 多；黄金持续 contango → 持仓成本压制 → 中性偏空。

### 6.3 多因子综合评分

**Z 标准化加权**：`score = Σ w_i × (factor_i - mean_i) / std_i`，常用 `w = [0.4, 0.3, 0.3]`（carry + momentum + value）。

**实战**：每周末复盘时算出 G10 货币的 Z 分数排序，结合宏观 regime 选 1–2 个做多 / 做空。

## 七、协整与配对交易

### 7.1 协整（Cointegration）

**含义**：两个非平稳序列（价格）线性组合后平稳 → 长期均衡关系。
**检验**：Engle-Granger 两步法 / Johansen 检验（多变量）。

**手工简化**：算两只品种的 252 日对数价格 `β × P_A - P_B` 的 ADF 平稳性 p-value；p < 0.05 即协整。

### 7.2 配对交易信号

**Z-score**：`z_t = (spread_t - μ) / σ`，阈值 `|z| > 2` 开仓，`|z| < 0.5` 平仓。

**半衰期**（AR(1)）：`HL = -ln(2)/ln(φ)`，决定**持仓时间尺度**。HL 太长（如 > 60 日）则配对交易不实用。

**陷阱**：
- 协整关系**会断裂**（结构性变化），定期重检；
- 配对交易有方向性风险（β 估计错误时单边亏）；
- 杠杆产品（外汇/期货）的配对交易还需考虑利率差 / 库存费。

## 八、Hurst 指数与均值回归

### 8.1 Hurst 指数 H

`H = 0.5`：随机游走（无记忆，价格不可预测）；
`H < 0.5`：均值回归（价格围绕均值震荡，反转策略有效）；
`H > 0.5`：趋势（动量延续，趋势策略有效）。

**计算**：R/S 法（rescaled range）。`quant_metrics.py` 已实现。

### 8.2 实战应用

- **H < 0.45**（如 USDJPY 横盘）：用 Z-score 反转、布林带回归、网格区间；
- **0.45 ≤ H ≤ 0.55**：区间/突破皆可，缩短持仓时间；
- **H > 0.55**（如黄金牛市）：纯趋势跟踪，回调入场，不猜顶；
- **H > 0.7**：强趋势，**禁止**逆势加仓（"all in" 是常见死法）。

### 8.3 Z-score 综合用法

`Z-score_63d`（63 日 ≈ 一季度）是最实用的偏离度指标：
- `|Z| > 2`：超买/超卖，**警惕反转**（但趋势品种可能继续极端）；
- `|Z| < 0.5`：中性区间，结构不明确，宜观望；
- 趋势品种 + Z > 2：不要逆势，反转信号要等 Z 拐头；
- 区间品种 + Z > 2：可入场反转。

### 8.4 多重分形（Multifractal，Mandelbrot）

**关键洞见（Mandelbrot《市场的(错误)行为》）**：单一 Hurst 指数 H 是"平均粗糙度"，**掩盖了市场的多重分形结构**——价格在不同时间尺度上自相似程度不同（趋势段 H 高、震荡段 H 低）。

**对 v1.3.0 的含义**：
- 单一 H 只是"该序列当前主导 regime"的近似；H ≈ 0.5 不代表"纯随机"，而是"趋势与均值回归两种力量均衡"；
- 市场风险是**分形**的：极端事件比正态分布预测的频繁得多（厚尾的几何来源）；
- 不能用单一时窗的 H 做长期决策，应**分时窗重估 H**（如 21d / 63d / 252d 各算一个），观察 H 的时变特征。

**实战**：`quant_metrics.py` 输出的 Hurst 是"当前样本窗"的 H，用于**当下 regime 判定**而非长期定性；若 21d H > 0.6 而 252d H < 0.45，说明"长期区间、短期突破"，应按短期趋势操作但警惕均值回归反转。

## 九、相关性与组合分散

### 9.1 皮尔逊相关系数

**公式**：`ρ = cov(A,B) / (σ_A × σ_B)`，范围 `[-1, 1]`。

**陷阱**：
- 滚动相关性 regime 切换：危机时相关性全部趋近 +1（分散失效）；
- 线性相关不捕捉尾部相依性——用 **Copula** 或**最大相关性**改进；
- 负相关 ≠ 对冲：只有在价差**稳定**时才是好对冲。

### 9.2 跨品种相关性矩阵（手工监控）

核心对：
- DXY ↔ 黄金：典型负相关（−0.7 至 −0.9）；
- US10Y ↔ DXY：强正相关（+0.6 至 +0.8）；
- WTI ↔ CAD：正相关（+0.5 至 +0.7）；
- AUDJPY 内部：AUD ↔ JPY 弱相关 → 高波动 carry pair。

**监控频率**：周度更新，相关性突破 ±0.2 即检查宏观 regime 是否切换。

### 9.3 等权/风险平价/最大分散

| 组合方法 | 公式 | 优势 | 劣势 |
|---|---|---|---|
| 等权 (EW) | `w_i = 1/N` | 简单 | 高波动品种拖累组合 |
| 风险平价 (RP) | `w_i = 1/σ_i / Σ` | 风险均衡 | 估计风险不稳定 |
| 最大分散 (MD) | `w ∝ Σ^{-1} σ` | 分散最大化 | 需要协方差矩阵估计 |

**手工推荐**：2–3 个策略 + 风险平价权重的简化版即可。

## 十、实战纪律（量化陷阱）

### 10.1 过拟合

**表现**：回测 Sharpe = 3，实盘 Sharpe = 0.3。
**成因**：参数过多（"曲线拟合"）、样本太少、回测区间包含特定 regime。

**防范**：
- **参数 ≤ 3 个**：每个可调参数至少需 30 笔独立样本；
- **样本外测试**：70% 训练 / 30% 测试，**不重复**触碰测试集；
- **walk-forward 验证**：滚动窗口重训 + 验证，模拟真实使用；
- **多 regime 测试**：至少覆盖趋势 + 震荡 + 危机三种 regime。

### 10.2 前视偏差（Look-Ahead Bias）

**表现**：用了未来才知道的数据（如 NFP 后回测但用了 NFP 公布前的预期值反向开仓）。
**防范**：所有回测时间戳精确到 bar close；只用 close 价及其衍生指标；Z-score 用 rolling 不用 expanding。

### 10.3 生存偏差（Survivorship Bias）

**表现**：只用现存标的回测，忽略退市品种。
**防范**：包含退市品种（外汇退市少，主要影响股票/商品）；手动补全已下架合约历史。

### 10.4 交易成本

**现实清单**：
- 外汇点差：0.5–2 pip（主要货币对 0.5–1.0 pips）；
- 库存费（Swap）：±0.5–5 pips/天（持仓过夜）；
- 滑点：NFP/FOMC 期间 2–10 倍日常点差；
- 佣金（ECN）：0.3–0.7 pips/边。

**回测必须**扣除这些。策略期望值 EV 必须 ≥ 2× 总交易成本，否则长期亏损。

### 10.5 心理与执行

**量化纪律检查清单**（每周末逐项打勾）：
- [ ] 单笔风险 ≤ 1%？
- [ ] 总组合风险 ≤ 5%？
- [ ] 最大回撤 < 15%？
- [ ] 连续亏损 3 次后强制暂停 ≥ 24h？
- [ ] 过去 30 笔 EV > 0.2R？
- [ ] 跨品种相关性 < 0.7（避免重复暴露）？
- [ ] 至少 2 个不同 regime 的样本各 20 笔？

## 十二、信息比率与主动管理基本定律（Grinold & Kahn）

### 12.1 信息比率（Information Ratio, IR）

**定义**：`IR = 主动收益 / 主动风险 = (组合收益 - 基准收益) / 跟踪误差`

**解读**：
- IR < 0.3：勉强；
- IR 0.5：合格（机构级）；
- IR 0.75：优秀；
- IR > 1：顶尖（极罕见，警惕过拟合）。

**手工映射**：把"基准"设为"不做交易的资金（≈ 0 收益 / 0 风险）"，则主动收益 = 你的策略收益，跟踪误差 = 策略波动率 → IR ≈ 年化 Sharpe（对现金基准）。

### 12.2 主动管理基本定律（Fundamental Law of Active Management）

**公式**：`IR ≈ IC × √BR`

- **IC（信息系数）**：预测与结果的相关性（技能质量）。IC = 0.05 表示"预测只比随机好 5%"，已是优秀水平；
- **BR（广度）**：独立预测次数（机会数量）。

**实战含义**：
- **手工交易者靠"广度"取胜难**（BR 低），必须靠 **IC 高**（高质量、少而精的预测）——这正对应本技能的"筛选 1–3 个高确定性机会，不盯 10 个品种"；
- 想提升 IR：要么提高每次判断的准确率（IC↑，深耕品种/宏观），要么增加独立机会（BR↑，跨品种但需控制相关性）；
- **例**：IC = 0.05、BR = 100 → IR = 0.5（合格）；IC = 0.03、BR = 30 → IR = 0.16（不合格，需放弃或改进）。

**与三维印证衔接**：三维印证本质是"用多重独立维度提升单次判断的 IC"，量化验证是"用指标约束避免 IC 为负时硬做"。
