# 通道、趋势线与经典图表形态

> **定位**:通道与图表形态是"盘面结构"的核心载体——它们把宏观方向落实为**可画、可量、可交易的具体边界**。形态给出"方向偏好",突破+量能给出"时机",度量目标给出"止盈"。
> 本文件对应 Murphy《金融市场技术分析》第 4 章(趋势线与通道)、第 5–6 章(形态)。
> 与 `ta_reading.md`(K 线)、`indicators.md`(均线/MACD/ATR)配套使用。

---

## 1. 趋势线(一切通道的地基)

- **画法**:连接两个依次抬升的低点(上升趋势线)或两个依次降低的高点(下降趋势线)。**至少 2 点可画,3 点确认**——被第 3 点触碰不破,趋势线才有效。
- **斜率**:趋势线越陡越脆弱(易假突破);平缓的趋势线更可靠。
- **重绘纪律**:随价格推进用新摆动点修正趋势线;**不要为了贴合而强行穿过 K 线实体**。
- **突破判定**:收盘有效跌破上升趋势线(尤其放量)= 上升趋势转弱/终结预警;反之突破下降趋势线=转强。

---

## 2. 通道(Channel / 轨道)

通道 = 一条趋势线 + 一条与之**平行**的轨线,价格在两线之间运行。

### 2.1 三种通道

| 类型 | 结构 | 含义 | 交易法则 |
|------|------|------|----------|
| **上升通道** | 下轨上升、上轨平行上升 | 多头控盘,边涨边洗 | 回踩下轨做多;上轨减仓/不追高;跌破下轨=趋势警示 |
| **下降通道** | 上轨下降、下轨平行下降 | 空头控盘 | 反弹上轨做空;突破上轨=转强预警;只顺空 |
| **水平通道(矩形)** | 上下轨水平 | 供需均衡、震荡蓄势 | 高抛低吸;放量突破边界后顺势跟进 |

### 2.2 画法(两种)

- **几何法**:先画趋势线(连接 2–3 个摆动点),再作过"对侧极值点"的平行线。例如上升趋势线连接两个低点,上轨平行线过最近显著高点。
- **回归/统计法**:对收盘价做线性回归得**中线(median line)**,上下轨 = 中线 ± k×ATR 或 ±k×回归残差标准差(`kline_read.py` 的 `detect_channel()` 采用此思路,稳妥且自适应波动)。

### 2.3 通道交易要点

1. **顺通道方向**:上升通道只做多(下轨买),下降通道只做空(上轨卖);水平通道高抛低吸。
2. **中线(median line)**:通道中轴是"均值",价格偏离上轨易回落、偏离下轨易反弹;中线常作回调第一目标。
3. **通道突破与回踩(Throwback / Pullback)**:
   - **真突破**:收盘有效站上/下轨 + 放量,随后**回踩原轨线不破**并反向 = 趋势加速,可顺势跟进。
   - **假突破(流动性扫荡)**:价格瞬间刺穿轨线后**快速收回通道内**(打掉止损再反向)。假突破本身常是反向信号——在水平通道上轨假突破 = 做空机会,下轨假突破 = 做多机会。
4. **通道宽度用 ATR 表达**:轨距 ≈ 2×~3×ATR 属正常;过窄通道易假突破,过宽通道止损难设。

### 2.4 与指标衔接

- 上升通道内,RSI 触 70、MACD 柱缩短但价格仍贴下轨上行 = 强势钝化,**不以超买做空**,以跌破下轨/死叉为离场信号。
- 通道收口(上下轨靠拢)+ 布林收口 + ATR 收缩 = 三重收敛,**突破在即**,提前标定突破后的关键位与挂单区域。

## 3. 经典图表形态(反转 / 持续)

> 通用确认规则:**任何形态都以"突破+放量"为确认**;度量目标 = 形态垂直高度,从突破点向突破方向翻越。形态失败(回到形态内)即止损。

### 3.1 反转形态

| 形态 | 结构 | 方向含义 | 确认与度量 |
|------|------|----------|------------|
| **头肩顶/底** | 三峰(中峰最高)+ 两肩 + 颈线 | 顶=反转向下;底=反转向上 | 跌破(顶)/突破(底)**颈线**且放量;目标=颈线到头顶高度翻越 |
| **双顶(M顶)/双底(W底)** | 两个相近高点/低点 + 中间颈线 | 顶=反转;底=反转 | 跌破/突破颈线确认;目标=双顶高点到颈线高度翻越 |
| **圆底/圆顶** | 弧形缓缓转向 | 中长期反转 | 突破弧顶/弧底颈线;目标较模糊,以结构位为准 |
| **三重顶/底** | 三个相近极点 | 强反转(支撑/阻力经三次考验) | 突破第三 contacted 边界确认 |

**反转形态使用纪律**:
- 反转形态**只在趋势末端、关键位附近**才有意义;中段出现的"看似双顶"多为持续形态。
- 顶部形态(头肩顶/双顶)统计上比底部形态更可靠(与 `ta_reading.md` Morris"顶部形态更优"结论一致)。
- 反转形态本身**不逆宏观**:宏观仍强多时,出现的"双顶"很可能是持续中继,宁可错过不做逆。

### 3.2 持续形态(顺势中继)

| 形态 | 结构 | 含义 | 确认与度量 |
|------|------|------|------------|
| **三角形** | 收敛的两条趋势线 | 整理中继,突破方向顺原趋势概率高 | 突破任一边+放量;目标=三角形最宽处高度翻越 |
| ├ 对称三角 | 上下轨均收敛 | 方向待定,突破跟随 | 同上 |
| ├ 上升三角 | 上轨水平、下轨上升 | 偏多中继 | 向上突破概率高 |
| └ 下降三角 | 下轨水平、上轨下降 | 偏空中继 | 向下突破概率高 |
| **旗形(Flag)** | 与趋势反向的短暂平行四边形(急涨后小斜向下) | 强势中继 | 沿原趋势方向突破旗形上/下边;目标=旗杆高度翻越 |
| **三角旗(Pennant)** | 小三角形,前有大旗杆 | 中继(比旗形更短) | 同旗形 |
| **楔形(Wedge)** | 两条同向收敛趋势线(都上倾或都下倾) | 反向中继(上升楔形看跌,下降楔形看涨) | 突破楔形边界;**楔形方向与趋势相反时才是中继** |

**持续形态使用纪律**:
- 持续形态默认**顺原趋势突破**;在上升通道中出现的旗形,只在突破上边时做多。
- 形态内的"假突破"常见,必须等**收盘确认 + 量能**,不抢突破瞬间。

## 5. 扇形线(Speed Lines / Fan Lines)

- **画法**:从显著低点(上升趋势)或高点(下降趋势)出发,按**趋势角度的 1/3、2/3、3/3** 作三条射线(等价于 33% / 66% / 100% 的回撤斜率)。价格回撤至某条扇形线后弹起 = 该线为支撑。
- **含义**:扇形线是"动态支撑 / 阻力带",比单一趋势线更鲁棒;价格逐条下破第一条→第二条→第三条,视为趋势**逐级转弱直至反转**的确认。
- **与趋势线互补**:先画主趋势线(§1),被有效跌破后再用扇形线细化回调层级,避免为贴合而频繁重绘。

---

## 6. 回撤比例与斐波那契(Retracements)

- **Murphy 经验回撤位**:趋势回调常见 **33% / 50% / 66%**(注意不是仅 61.8%)——与前面高低点、均线共同构成"回调入场区"。
- **斐波那契**:0.382 / 0.5 / 0.618 为最常用回撤与扩展位;0.618–0.786 视为"黄金回撤带",用于标定回调买点;1.272 / 1.618 为扩展目标(度量持续 / 反转形态高度时同理)。
- **用法纪律**:
  - 上升趋势中,价格回撤至 **50%–61.8%(或 Murphy 的 50%–66%)** + 均线 / 前低支撑 + K 线触发(见 `ta_reading.md`)= 高胜率顺势买点。
  - 跌破 **66% / 0.786** 视为趋势结构破坏,原顺势逻辑失效,谨慎。
  - 回撤位与整数关口、成交密集区(POC)重合时,支撑 / 阻力强度倍增。

## 7. 形态 + 通道 + 指标 综合实战流程

以"日线上升通道中的回踩做多"为例:

1. **宏观定方向**:实际利率下行/美元偏弱 → 黄金偏多(方向地基)。
2. **跨市场验方向**:TIPS 走弱 + 铜走强 → 共振偏多。
3. **盘面定结构(本文件)**:日线处上升通道,价格回踩**下轨 + 20EMA** 附近。
4. **指标确认(`indicators.md`)**:日线 MACD 零轴上方、RSI 自 50 反弹、ATR 正常;1H MACD 柱由缩转放、金叉。
5. **K 线触发(`ta_reading.md`)**:下轨处出现**已确认的看涨吞没/倒锤子线**(Morris 统计正期望 + 次日确认)。
6. **执行**:入场=下轨上方小破位;止损=下轨 − 1.5×ATR(结构外);目标1=中线,目标2=上轨;仓位按 `position_size.py`(单笔风险 0.5%–1%)。

**任一环节反向即降级**:宏观转空→放弃做多;下轨被有效跌破→形态失败止损;指标背离→不追、等重新站回。

> 通道与形态回答"边界在哪、方向偏好、目标多远";指标回答"动能/波动/超买超卖是否配合";K 线回答"具体哪一根触发"。三者必须共同收敛,才构成可执行的盘面时机。
