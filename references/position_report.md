# 分析报告统一模板 v1（v1.4.0 新增 · v1.4.1 强制覆盖 · v1.4.2 默认标的与判定规则细化）

> **本模板是本技能「唯一批准的分析报告骨架」**——覆盖三类输出:
> ① 持仓深度诊断(已有持仓) ② 多品种 / 单品种交易计划 ③ 专项行情分析。
> 源自用户 2026-09-10 确认的 v1.3.1 AUDJPY 持仓分析报告(深空蓝霓虹暗色版面),**强制套用,禁止脱离模板自由发挥版面**。
> HTML + MD 双版本必须格式一致;纪律(第⑨节)永远置末。

## 0. 适用范围与第①节适配规则

| 报告类型 | 第①节标题 | 第①节卡片内容 | 第⑦节内容 |
|----------|-----------|----------------|-----------|
| **持仓深度诊断** | 持仓快照 | 品种方向 / 入场→当前 / 浮盈 pips+USD / SL·TP·剩余 RR | 持仓健康度 5 维评分 + 3 情景(稳健/进取/激进)+ 最终推荐 |
| **多品种 / 单品种交易计划** | 分析标的快照 | 每品种:实时价 / ATR(14) / EMA20·EMA50 / 趋势判定 / 计划方向(买/卖) | **可交易则给交易计划(含平仓计划),不可交易则输出「不建议建仓」+ 理由**;按品种分别判定 |
| **专项行情分析** | 分析标的快照 | 同交易计划(单一或少数品种) | 结论(做多/做空/不交易)+ 触发与失效条件 |

> **统一约束**:
> - 持仓类一键走 `scripts/position_report.py`;非持仓类基于本模板手动/半自动填充后输出 HTML + MD。
> - 第②~⑨节结构**三类完全一致**,仅第①节与第⑦节按上表适配;第⑨节(纪律)永不前移。
> - 数值保留 2 位小数;结论禁用"可能/或许"等模糊词。

## 2. 视觉规范（HTML）

### 2.1 配色
- **背景**：`linear-gradient(135deg, #0a0e27 0%, #1a1f3a 50%, #0d1b2a 100%)`（深空蓝）
- **卡片**：`linear-gradient(135deg, #1c2541, #0b132b)`
- **强调绿**：`#2ecc71`（利多、顺风、达标）
- **强调红**：`#e74c3c`（利空、风险、警告）
- **强调黄**：`#f1c40f`（中性、关键、当前）
- **强调蓝**：`#3498db`（入场、计划、待办）
- **强调紫**：`#9b59b6`（央行、议息）

### 2.2 图表规范（ECharts）
- **K 线**：candlestick，涨绿跌红（**注意**：A 股惯例是红涨绿跌，但外汇/商品 K 线用国际惯例绿涨红跌），含 4 条 markLine（入场蓝、SL 红虚线、TP 绿虚线、当前黄实线），dataZoom 默认显示最近 50%
- **柱状图**：跨市场对比用 bar，渐变色按方向
- **雷达图**：6 维度（|Hurst| / |Z| / |Sharpe| / |Sortino| / |Skew| / VaR×10），日线+1H 双系列对比；**容器 `.chart-small` 高度 ≥360px**，radar 配置 `radius:'55%'`、`center:['50%','54%']`，避免图例/tooltip/雷达顶点超出容器边界
- **主题**：`backgroundColor:'transparent'`，tooltip 背景 `rgba(20,30,60,.9)`，文字白色

### 2.3 数据精度
- **价格**：5 位小数（外汇 JPY 对）
- **百分比**：2 位小数
- **指标数值**：4 位有效位
- **金额**：2 位小数 USD
- **时间戳**：`YYYY-MM-DD HH:MM GMT+8`

## 3. 数据获取流程

### 3.1 必备数据源
```
iTick forex API       → AUDJPY / USDJPY / AUDUSD / XAUUSD 实时报价
Twelve Data API        → 日线 60 根 + 1H 120 根 OHLC
BIS WS_CBPOL           → RBA / BoJ / Fed / ECB 政策利率
FRED DGS10 / T10Y2Y   → 美债 10Y + 曲线利差
jin10 list_calendar    → 当日已公布 + 待公布 + 本月议息
jin10 list_news        → 财经早餐关键快讯
quant_metrics.py       → 6 类量化指标（基于 OHLC）
```

### 3.2 调用顺序
```
1. 时间核对（v1.2.2 铁律）：取系统时间作为报告基准
2. iTick 拉取 4 个实时报价（限频 5 次/分钟，分批 sleep 15s）
3. kline_fetch.py 抓取日线 200 根 + 1H 200 根
4. quant_metrics.py 计算日线 + 1H 指标
5. bis_fetch.py 拉取央行政策利率
6. fred_fetch.py 拉取美债
7. jin10_mcp.py list_calendar + list_news
8. 三角验证：USDJPY × AUDUSD vs AUDJPY
9. 数据汇总 → 模板填充 → 输出 HTML + MD
```

## 3.4 利差结构表规范（v1.4.2）

第②节 2.2「利差结构（套息交易视角）」必须固定 3 行：

| 利差对 | 示例 | 解读重点 |
|--------|------|----------|
| **US 2s10s** | T10Y2Y 或 DGS10−DGS2 | 曲线形态(陡峭/倒挂)对美元强弱、风险偏好的指示 |
| **利差最大货币对 #1** | 如 US 10Y − JP 10Y | 美日利差对 USDJPY 套息/反套息的驱动 |
| **利差最大货币对 #2** | 如 AU 10Y − JP 10Y | 澳元/日元交叉盘与商品货币方向 |

- 数值可用央行政策利率差近似(若无 10Y 国债利差)。
- 解读须明确：利差收敛/扩大 → 对应货币对方向。

## 3.5 关键位规范（v1.4.2）

第⑤节 5.2「关键位」改为**表格形式**,每个标的 1 行：

| 品种 | 关键位 | 类型 | 作用/触发条件 |
|------|--------|------|---------------|
| XAUUSD | 4350.00 | 支撑 | EMA50 与 20 日低点重合,回踩触发 BUY Limit |
| EURUSD | 1.1500 | 支撑 | 跌破则趋势转空,作为 SELL Stop 触发 |
| USDJPY | 155.60 | 阻力 | 反弹至此受阻,作为 SELL Limit 触发 |

- **类型仅三选一**:支撑 / 阻力 / 中枢。
- 每品种仅列**一个最关键位**,禁止多个关键位堆叠在同一卡片。
- 必须注明该关键位的交易触发条件(回踩/突破/跌破)。

## 3.6 宏观大事综合规范（v1.4.2）

第②节 2.4「宏观大事综合」中,**每个标的必须列出 2 条影响最大的宏观事项**,格式：

```
【XAUUSD】① 美国 CPI(09-11 20:30):若核心 CPI 超预期→实际利率上行→金价承压。 ② FOMC(09-16-17):降息预期计价程度决定黄金是否买预期卖事实。
【EURUSD】① ECB 利率决议(09-10 20:15):加息 25bp 至 2.50% 已充分计价,关注拉加德措辞。 ② 美国 CPI/FOMC:欧美利差与美元反向驱动 EURUSD。
...
```

- 事项须具体(数据/央行/地缘/政策)。
- 允许部分事项跨品种重复(如 Fed/CPI 影响多个品种),但每个品种须给出**差异化影响路径**。
- 避免空泛表述(如"全球经济形势"),必须落实到价格波动机制。

## 4. 操作建议输出标准

### 4.1 交易计划判定规则（v1.4.2 重大调整）

第⑦节「综合判定与操作建议」按实际可交易性**二选一**输出,禁止一刀切：

**A. 可交易（三维共振 + 结构触发 + 风险可控）**
- 宏观/跨市场/盘面方向一致；
- 存在明确关键位触发条件；
- 单笔风险 ≤2%（小账户 ≤1%）、RR ≥1.5、手数在经纪商最小手数之上；
- 不在重大事件前 4h / 议息前 24h 的高风险窗口内（或事件已落地）。
- 输出交易计划表（见 4.2）。

**B. 不建议建仓（任一条件不满足）**
- 三维未共振、信号冲突、重大事件窗口流动性差、ATR 过大导致小账户风险超标、无合格 RR、关键位远离现价超过 2 倍 ATR 等。
- **直接输出「不建议建仓」并给出 2-3 条具体理由**；
- 空仓即结论,禁止硬凑交易计划。

> 同一报告中不同标的分别判定：部分给交易计划,部分给不建议建仓。

### 4.2 交易计划表字段（v1.4.2 含平仓计划）

| 字段 | 示例 | 说明 |
|------|------|------|
| 交易品种 | USDJPY | — |
| 方向 | SELL | Buy / Sell |
| 挂单类型 | Limit / Stop | 回踩关键位用 Limit;突破用 Stop |
| 入场价格 | 154.65 | 精确到品种所需小数位 |
| 止损价格 | 156.39 | 结构外 1.5×ATR 或前高/前低外扩 |
| 止盈目标 1 | 150.00 | 盈亏比 1:1,触发后平仓 50% |
| 止盈目标 2 | 147.50 | 盈亏比 1:2,触发后移动止损并持有剩余 |
| 建议手数 | 0.005 | 由 `position_size.py` 按 1% 风险反推 |
| 单笔风险 | $5.65 (0.99%) | 风险金额 + 占账户比例 |
| **平仓计划** | 触发 TP1 平 50% 并移 SL 至入场;触发 TP2 再平 30%;剩余 20% 推保护性止损持有或遇反向 EMA 交叉全平 | 必须明确分步平仓与止损移动规则 |
| 计划失效条件 | 1h 内未触及入场价;价格反向突破 155.60;FOMC 前 4h 仍未成交 | — |

- 平仓计划是**必填项**,缺失则视为输出不完整。

### 4.3 持仓健康度评分（满分 100）
| 维度 | 满分 | 加分条件 |
|------|------|----------|
| 趋势 | 25 | H>0.55 + 周/日空头排列 +25；H>0.55 仅 1 周期 +15；H<0.5 -10 |
| 宏观 | 25 | 三大利空/利多叠加 +25；两项叠加 +20；一项 +12；冲突 +5 |
| 跨市场 | 20 | ≥3 个相关市场同向 +20；2 个同向 +15；1 个 +8；背离 0 |
| 量化 | 15 | Sharpe>1 + Sortino>1.5 + MDD<5% +15；达标 3/4 +10；达标 2/4 +5 |
| 行为 | 15 | 已设 SL/TP + 仓位 ≤2% + RR>1.5 +15；缺一项 -5 |

### 4.2 情景分类
- **🅰 稳健派**（⭐⭐⭐⭐）：移动 SL 至入场+缓冲，保留全部仓位
- **🅱 进取派**（⭐⭐⭐⭐⭐ 推荐）：减仓 50% + 移动 SL 至关键位 + 剩余分步走
- **🅲 激进派**（⭐⭐）：持仓不动，依赖大趋势延续

### 4.2a 最终推荐必须附「抉择依据」(v1.4.3)
在第⑦节「最终推荐」结论后，必须新增一段「抉择依据」，格式：
```
🧭 抉择依据：情景A...；情景B...；情景C...。本报告选择情景B，原因：...
```
- 必须对 A/B/C 三方案各用一句话说明核心利弊；
- 明确解释为何推荐方案是最优解（风险/收益/纪律三者平衡）；
- 引用具体数字（锁定利润金额、剩余风险金额、RR、事件风险）。

### 4.3 关键时间窗
- **事件前 4h 不开新仓**（已持仓可不减但需主动平仓）
- **三大央行议息前 24h** 减仓或平仓
- **风险事件后 1h 复盘** 决定是否加仓
