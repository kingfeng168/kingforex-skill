# 持仓分析报告模板 v1（v1.4.0 新增）

> **本模板用于「持仓深度分析」专项报告**——不同于 `trade_plan_template.md`（盘前制定新计划），
> 本模板聚焦**已有持仓的全维度诊断**：宏观 → 跨市场 → 盘面 K 线 → 量化 → 操作建议 → 纪律。

## 1. 模板九大节结构（固定顺序）

| # | 章节 | 用途 | 必填数据 | 数据源 |
|---|------|------|----------|--------|
| ① | **持仓快照** | 4 卡片：品种方向/入场当前/浮盈/SL-TP | 品种、方向、手数、入场、SL、TP、当前价、浮盈 pips/USD、距 TP/SL pips | 用户输入 + iTick 实时报价 |
| ② | **宏观金融面解读** | 4 子节：央行政策路径 / 利差结构 / 地缘+风险偏好 / 综合 | 4 大央行利率、AU-JP 利差、避险指数、宏观大事 | BIS WS_CBPOL、FRED DGS10、jin10 list_news |
| ③ | **当日重要数据 + 本月议息会议提醒** | 3 子节：今日已公布 / 今日待公布 / 9 月议息 | 5-10 条日历事件 + 8 条央行议息 | jin10 list_calendar |
| ④ | **跨市场验证** | 1 柱图 + 1 表格，三角验证公式 | 6 个品种现价：AUDJPY/USDJPY/AUDUSD/XAUUSD/DGS10/T10Y2Y | iTick + FRED |
| ⑤ | **多周期共振（含真实 K 线）** | 日线 K 线图（60 根）+ 1H K 线图（120 根）+ 4 条 markLine（入场/SL/TP/当前）+ 方向矩阵表 + 关键位 | OHLC 数据 + 入场/SL/TP/当前价 | Twelve Data（kline_fetch.py） |
| ⑥ | **量化验证（v1.3+）** | 雷达图 + 收益分布柱图 + 日线/1H 指标双表 | 价格序列 → 跑 quant_metrics.py 输出 | quant_metrics.py |
| ⑦ | **综合判定与操作建议** | 5 维度评分表 + 3 情景卡（稳健/进取/激进）+ 最终推荐（进取派优先） | 持仓健康度评分 | 综合计算 |
| ⑧ | **引用与依据** | 数据源表 + 8 卡片方法论 | 5 条数据源 | — |
| ⑨ | **交易纪律（v1.3+）** | 6 子节：仓位/入场/持仓/离场/复盘/心理纪律 | 6 大纪律卡片 | — |

> ⚠️ **第 ⑨ 节永远在最后**——任何"操作建议"必须在纪律之前呈现，让读者先看推荐、再看纪律铁律。

## 2. 视觉规范（HTML）

### 2.1 配色
- **背景**：`linear-gradient(135deg, #0a0e27 0%, #1a1f3a 50%, #0d1b2a 100%)`（深空蓝）
- **卡片**：`linear-gradient(135deg, #1c2541, #0b132b)`
- **强调绿**：`#2ecc71`（利多、顺风、达标）
- **强调红**：`#e74c3c`（利空、风险、警告）
- **强调黄**：`#f1c40f`（中性、关键、当前）
- **强调蓝**：`#3498db`（入场、计划、待办）
- **强调紫**：`#9b59b6`（央行、议息）

### 2.2 图表规范（ECharts）
- **K 线**：candlestick，涨绿跌红（**注意**：A 股惯例是红涨绿跌，但外汇/商品 K 线用国际惯例绿涨红跌），含 4 条 markLine（入场蓝、SL 红虚线、TP 绿虚线、当前黄实线），dataZoom 默认显示最近 50%
- **柱状图**：跨市场对比用 bar，渐变色按方向
- **雷达图**：6 维度（|Hurst| / |Z| / |Sharpe| / |Sortino| / |Skew| / VaR×10），日线+1H 双系列对比
- **主题**：`backgroundColor:'transparent'`，tooltip 背景 `rgba(20,30,60,.9)`，文字白色

### 2.3 数据精度
- **价格**：5 位小数（外汇 JPY 对）
- **百分比**：2 位小数
- **指标数值**：4 位有效位
- **金额**：2 位小数 USD
- **时间戳**：`YYYY-MM-DD HH:MM GMT+8`

## 3. 数据获取流程

### 3.1 必备数据源
```
iTick forex API       → AUDJPY / USDJPY / AUDUSD / XAUUSD 实时报价
Twelve Data API        → 日线 60 根 + 1H 120 根 OHLC
BIS WS_CBPOL           → RBA / BoJ / Fed / ECB 政策利率
FRED DGS10 / T10Y2Y   → 美债 10Y + 曲线利差
jin10 list_calendar    → 当日已公布 + 待公布 + 本月议息
jin10 list_news        → 财经早餐关键快讯
quant_metrics.py       → 6 类量化指标（基于 OHLC）
```

### 3.2 调用顺序
```
1. 时间核对（v1.2.2 铁律）：取系统时间作为报告基准
2. iTick 拉取 4 个实时报价（限频 5 次/分钟，分批 sleep 15s）
3. kline_fetch.py 抓取日线 200 根 + 1H 200 根
4. quant_metrics.py 计算日线 + 1H 指标
5. bis_fetch.py 拉取央行政策利率
6. fred_fetch.py 拉取美债
7. jin10_mcp.py list_calendar + list_news
8. 三角验证：USDJPY × AUDUSD vs AUDJPY
9. 数据汇总 → 模板填充 → 输出 HTML + MD
```

## 4. 操作建议输出标准

### 4.1 持仓健康度评分（满分 100）
| 维度 | 满分 | 加分条件 |
|------|------|----------|
| 趋势 | 25 | H>0.55 + 周/日空头排列 +25；H>0.55 仅 1 周期 +15；H<0.5 -10 |
| 宏观 | 25 | 三大利空/利多叠加 +25；两项叠加 +20；一项 +12；冲突 +5 |
| 跨市场 | 20 | ≥3 个相关市场同向 +20；2 个同向 +15；1 个 +8；背离 0 |
| 量化 | 15 | Sharpe>1 + Sortino>1.5 + MDD<5% +15；达标 3/4 +10；达标 2/4 +5 |
| 行为 | 15 | 已设 SL/TP + 仓位 ≤2% + RR>1.5 +15；缺一项 -5 |

### 4.2 情景分类
- **🅰 稳健派**（⭐⭐⭐⭐）：移动 SL 至入场+缓冲，保留全部仓位
- **🅱 进取派**（⭐⭐⭐⭐⭐ 推荐）：减仓 50% + 移动 SL 至关键位 + 剩余分步走
- **🅲 激进派**（⭐⭐）：持仓不动，依赖大趋势延续

### 4.3 关键时间窗
- **事件前 4h 不开新仓**（已持仓可不减但需主动平仓）
- **三大央行议息前 24h** 减仓或平仓
- **风险事件后 1h 复盘** 决定是否加仓
