# 模块二 · 外汇专项技能

## 1. 货币分类

- **避险货币**:美元(USD)、日元(JPY)、瑞郎(CHF)。风险恶化时走强。
- **商品货币**:澳元(AUD)、加元(CAD)、挪威克朗(NOK)、纽元(NZD)。与大宗、全球增长正相关。
- **融资货币**:日元、瑞郎(低息),套息交易中被借出。

## 2. 利率平价与套息(Carry)

- 抛补利率平价(CIP):远期汇率由两国利差决定,`F = S × (1+i_d)/(1+i_f)`。
- 套息逻辑:做多高息、做空低息,赚利差;但需承担汇率波动与平仓风险。
- **套息平仓信号**:①风险情绪恶化(VIX 跳升、股指大跌);②利差收窄(高息国降息或低息国加息)。平仓时高息货币急跌、日元瑞郎急涨。
- 监控 `AUD/JPY`、`USD/CAD` 作为风险偏好与商品需求的实时温度计。

## 3. 美元微笑理论(Dollar Smile)

- **左翼(全球避险)**:避险需求推升美元(即使美国走弱)。
- **底部(美国相对弱)**:美国增长落后于其他经济体,美元偏弱。
- **右翼(美国强)**:美国经济强劲、加息,美元走强。
判断当前处于哪一翼,决定美元交易方向。

## 4. CFTC 持仓判断拥挤度

- 读 COT(期货期权)与 TFF(期货-only)报告,看**非商业净头寸**与历史分位。
- 极度净多 + 处历史高位 → 拥挤,反转风险大(如 2021 年美元空头顶寸);极度净空同理。
- 用 `references/microstructure.md` 的持仓读法与位置。
- 应用:某货币对净头寸极端时,顺向追单需谨慎,等回调或反转信号。

## 5. 基本面长周期驱动

- **经常账户**:顺差国货币长期有支撑(如日本、德国 historically)。
- **资本流动**:股债资金流入推升本币;利差与风险偏好驱动组合流。
- 用"双赤字"(财政+经常账户)评估美元长周期压力。

## 6. 事件前"情景—反应"计划

非农 / CPI / FOMC 前,不做方向押注,做**情景树**:
- 数据强于预期 + 美联储鹰派 → 美元涨,(商品货币/黄金)跌。
- 数据弱于预期 + 美联储鸽派 → 美元跌,黄金/商品货币涨。
- 数据强但央行鸽 / 数据弱但央行鹰 → 预期差,优先观察不追。
套用 `assets/scenario_plan_template.md`。
