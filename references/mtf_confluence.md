# 多周期共振(三维印证)分析方法论 · `scripts/mtf_confluence.py`

> 本文件是 kingforex-skill「三维印证」哲学在**盘面**维度的落地细则:把"宏观定方向、跨市场验方向、盘面定时机"中的**盘面时机**进一步拆成「周线/日线定方向背景 + 1 小时定进场触发」,并用 `mtf_confluence.py` 把判断变成**可计算、可溯源、结论不含糊**的引擎。

---

## 0. 为什么必须"看大做小"

单一周期的信号噪声极大。价格在 1H 上的一根吞没,放到日线可能只是趋势中的正常回踩;日线上的反转形态,放到周线可能只是更大级别上涨途中的中继。因此:

- **大周期(W/D)定"该不该做、往哪做"**——方向背景、关键位、波动尺度。
- **小周期(1H)只定"现在这个点能不能进"**——触发与止损位置。**逆大周期的单子不做**(魏强斌《外汇交易进阶》第十八阶"多重时间框架":大周期趋势是"气候",小周期是"天气",天气不可逆气候)。

> 权威背书(IMA 知识库 `金融` id `7490653902604963`):
> - 魏强斌《外汇交易进阶——从新手到大师的成功之路》(下) **第十八阶·多重时间框架分析**:明确"高阶时间框架定方向、低阶时间框架定入场"的层级原则,禁止跨周期反向交易。
> - 《ATR止损法深度研究与实践指南.docx》:止损必须用 ATR 作为波动尺(本引擎触发止损默认 `1.5×ATR_1H`)。
> - 鲍里斯·斯克斯伯格《外汇市场技术分析》、魏强斌《外汇狙击手》:支撑/阻力/趋势线/均线系统作为关键位与趋势判定的基础工具。

> 数值规则以本技能的本地参考为准(已体系化提炼,可直接代码化):
> - 关键位与盘面清单 → `references/ta_reading.md`(§1 多周期框架、§4 关键位体系、§8 盘面清单)
> - 均线 / ATR / MACD / RSI / 布林 / 随机 / ADX → `references/indicators.md`(§1 均线、§2 ATR、§8 组合模板"日线定背景/1H 找触发表"、§9 ADX)
> - 趋势线 / 通道 / 扇形线 / 斐波回撤 → `references/channels.md`

## 1. 三维共振的引擎化定义

引擎对三个周期(周线 W、日线 D、1 小时 H1)各调用 `kline_read.analyze()` 得到单周期客观解读,再在聚合层做四件事:

### ① 方向共识矩阵
每个周期从三项客观输入投票:
- `trend_context`(趋势背景:up/down/range,来自 ATR 归一化摆动斜率)
- `trend_ema`(EMA20/50 排列:多头/空头/反弹/回落/纠缠)
- `structure`(摆动结构 HH/HL 或 LH/LL)

归类规则(见 `mtf_confluence.py:classify_bias`):
| 组合 | 方向 | 强度 |
|---|---|---|
| 趋势背景偏多 且 多头排列/反弹 | LONG | 强/中 |
| 趋势背景偏空 且 空头排列/回落 | SHORT | 强/中 |
| 其余(纠结/震荡/多空冲突) | NEUTRAL | 弱 |

### ② 大周期背景方向(W + D 收敛)
对 W、D 各打分:明确偏多 +1.0,明确偏空 −1.0,中性但价在 EMA50 上方 +0.5 / 下方 −0.5。
- 背景分 ≥ +1.5 → 大周期**看多**
- 背景分 ≤ −1.5 → 大周期**看空**
- 其余 → **中性(冲突)**

### ③ 关键位融合(confluence zone)
合并三周期的 `resistance`/`support`/`round_levels`,把**邻近(价格 ±0.3% 或 ±0.4×日线 ATR 容差内)**的位聚成一个"共振区",并按强度分级:
- 得分 ≥5 且跨 ≥2 周期 → **强**
- 得分 ≥3 或跨 ≥2 周期 → **中**
- 其余 → **弱**
- 角色:相对日线收盘价,标记为**支撑区 / 阻力区 / 中枢区**。

> 多周期在同一价位附近都出现关键位 = 市场记忆共振,该位被测试/反转的次数更多,可靠性显著高于单周期位。

### ④ ATR 跨周期差异量化
对比 `atr14` 在 W/D/1H 的值,算:
- `日线 ATR ÷ 1H ATR`(日线波动 ≈ 几个 1H ATR)——1H 触发止损必须用 1H ATR 度量,日线波动决定单笔大风险上限。
- `周线 ATR ÷ 日线 ATR`——大周期波动尺度。
- `1H 波动占现价 %` / `日线波动占现价 %`——当前波动 regime。

## 2. 明确结论(不可模棱两可)

引擎只在**大周期背景同向、且 1H 顺向(或回调至支撑区待转多)**时给"做多/做空";任一反向给"不交易 + 原因"。分支(见 `mtf_confluence.py:resolve`):

| 大周期(W+D) | 1H | 结论 | 动作 |
|---|---|---|---|
| 看多(≥+1.5) | 偏多/中性 | **做多** | 入场锚最近**支撑共振区**,止损=结构外 `1.5×ATR_1H`,目标=最近**阻力共振区**,算 R 倍数 |
| 看多 | 偏空 | **不交易** | 禁止逆大周期做空;等大周期支撑区 + 1H 转多触发 |
| 看空(≤−1.5) | 偏空/中性 | **做空** | 入场锚最近**阻力共振区**,止损=结构外 `1.5×ATR_1H`,目标=最近**支撑共振区** |
| 看空 | 偏多 | **不交易** | 禁止逆大周期做多;等大周期阻力区 + 1H 转空触发 |
| 中性(冲突) | 任意 | **不交易** | 周/日方向未共振,放弃,等 W/D 收敛 |

**禁令**:结论文本中不得出现"可能/或许/大概/观望待定"等模糊词。若给"做多/做空",必须同时给出具体入场区、止损、目标、R 倍数(全部来自客观数值);若给"不交易",必须指明冲突的周期与事实。

## 3. 用法

```bash
# 本地 CSV(每周期一个文件,已用 kline_read 验证的格式)
python scripts/mtf_confluence.py --csv-w W.csv --csv-d D.csv --csv-h1 H1.csv \
    --symbol USDJPY --html --json --out "D:/workbuddy/输出文件"

# 粘贴文本(每周期一段 OHLC,列:date,o,h,l,c[,v])
python scripts/mtf_confluence.py --text-w "..." --text-d "..." --text-h1 "..." \
    --symbol XAUUSD --html --json

# 联网抓取(Twelve Data,需 API Key;仅抓真实 OHLC,不编方向)
python scripts/mtf_confluence.py --fetch --symbol EURUSD --api-key <TWELVEDATA_KEY> --html --json
```

输出:`mtf_<SYMBOL>_<日期>.html`(ECharts 暗色图表:方向共识矩阵 + 关键位融合表 + ATR 跨周期差异柱状 + W/D/1H 三幅 K 线含 EMA20/50 与共振区标线 + 结论横幅)与同名 `.json`(结构化结论,供程序消费)。

> 与 `kline_read.py` 的关系:`mtf_confluence.py` 是"多周期聚合层",直接复用 `kline_read.analyze()` 做单周期解读,不重写指标计算;数据抓取复用 `kline_fetch.fetch_one`。

---

## 4. 数据质量要求(铁律)

- 每个周期建议 ≥60 根 K 线(W 至少 60 周、D 至少 120 日、1H 至少 120 根),样本不足 `kline_read` 会降级标注。
- 日线或 1H 任一缺失 → 引擎整体降级为"不交易"并说明缺哪个周期,绝不假装共振。
- 只消费真实传入/抓取的 OHLC;数据源只提供价格,不提供方向——方向由本引擎共识逻辑收敛。
