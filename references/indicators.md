# 技术指标详解(均线 · ATR · MACD · RSI · 布林带 · 随机 · 量能)

> **定位**:技术指标是"确认"与"过滤"工具,不是"方向"来源。指标的每一条信号都必须**顺宏观方向、验跨市场共振、落在盘面结构与关键位上**才有意义。  
> 裸指标信号在震荡市会反复打脸——本技能铁律:**指标只在结构/关键位处提供触发确认,绝不单独给方向**。  
> 本文件对应 Murphy《金融市场技术分析》第 7–10 章(移动平均、摆动指数、MACD、布林带等)。



---

## 0. 指标的三条使用铁律

1. **顺势**:指标信号若与宏观/跨市场方向相反,直接忽略。RSI 超卖 ≠ 抄底理由,超买 ≠ 摸顶理由。
2. **同质点不叠加**:用 5 个趋势指标(MACD+均线+布林+Parabolic+CCI)等于用 1 个——它们高度共线,不产生额外信息。
3. **周期分层**:大周期定指标的"背景"(日线 MACD 金叉=趋势背景偏多),小周期找触发(1H MACD 柱缩短=回调结束)。

推荐四类"正交"组合(各管一件事):

- **趋势**:均线排列(EMA20/50/200)、ADX
- **动量**:MACD、RSI、随机/KDJ
- **波动**:ATR、布林带宽度
- **量能**:成交量、OBV

## 1. 移动平均线(Moving Average,MA)

### 1.1 三种均线及取舍

| 类型      | 计算                  | 特点        | 适用             |
| ------- | ------------------- | --------- | -------------- |
| SMA(简单) | N 根收盘简单平均           | 平滑、滞后大    | 长周期定方向(50/200) |
| EMA(指数) | 赋予近期更大权重(α=2/(N+1)) | 反应快、贴合价格  | 中短周期触发(20EMA)  |
| WMA(加权) | 线性权重                | 比 EMA 更激进 | 少用             |

**FX/黄金/原油常用周期**(与 `kline_read.py` 默认一致):

- **20EMA**:短线趋势与动态支撑阻力(回踩不破=趋势健康)
- **50EMA**:中期趋势生命线
- **100 / 200EMA**:长线牛熊分水岭(机构关注位,常与市场结构位重合)

### 1.2 排列、交叉与信号

- **多头排列**:价格 > EMA20 > EMA50 > EMA200 → 强势上升趋势,只顺多。
- **空头排列**:价格 < EMA20 < EMA50 < EMA200 → 强势下降,只顺空。
- **均线缠绕**:EMA 反复交叉、无稳定排列 → 无趋势/震荡,均线失效,改用区间或离场。
- **金叉(看涨)**:快线(如 EMA20)上穿慢线(EMA50)→ 趋势转多确认。
- **死叉(看跌)**:快线下穿慢线 → 趋势转空确认。
- **回踩不破**:上升趋势中价格回踩 EMA20/50 后弹起,是顺势入场的高胜率位置(顺大周期方向时)。

### 1.3 常见陷阱

- 滞后性:均线在趋势反转后数根才反应,**不能用于拐点**,只能用于"趋势延续中跟车"。
- 震荡市金叉死叉频繁穿插(whipsaw),必须配合结构(区间边界)或量能过滤。
- **黄金/原油的大级别方向**常由 200EMA 与宏观(实际利率、美元)共同决定,均线只是技术印证。

### 1.4 衍生用法(选学)

- **均线包络(Envelopes)**:以均线为中轴 ±1%~3% 画上下轨,价格触上轨超买、下轨超卖(均值回归)。
- **均线带(Ribbon)**:叠加 5/10/20/50/100/200 多条均线,带子收拢=波动率收缩(突破前兆),带子发散=趋势展开。
- **EMA 通道**:用两条不同周期 EMA(如 EMA20 与 EMA50)夹出价格运行带,价格带外运行=加速段。

## 2. ATR(真实波幅,True Range)

> 详见 `ta_reading.md` §7 及 `scripts/kline_read.py`(`atr()` 函数)。此处补充进阶用法。

### 2.1 计算

- **TR** = max(当日高−当日低, |当日高−昨收|, |当日低−昨收|)
- **ATR(N)** = TR 的 N 日平均(常用 14)

ATR 衡量"一根 K 线平均波动多大",**与价格方向无关、与品种量纲无关**。

### 2.2 三大用途

1. **止损尺子**:止损距离 = 1.5×~2×ATR(依结构松紧)。高 ATR=宽止损+小仓位,低 ATR=窄止损。绝不用固定 20 点。
2. **吊灯止损(Chandelier Exit)**:
   - 多头:止损 = 近 N 日最高价 − k×ATR(k 常取 3)
   - 空头:止损 = 近 N 日最低价 + k×ATR
   - 优点:随趋势上移/下移,锁定利润且给波动留空间,比固定点数更科学。
3. **波动 regime 判定**:ATR 急速放大=事件/突破段;ATR 持续收缩=收敛(布林收口同向),警惕即将出方向。

### 2.3 与通道结合

通道上下轨常以"趋势线 ±k×ATR"或"回归线 ±k×ATR"构造(见 `channels.md`),ATR 是通道宽度的天然单位。

## 3. MACD(指数平滑异同移动平均)

### 3.1 构成(默认 12 / 26 / 9)

- **DIF(快线)** = EMA12 − EMA26
- **DEA(慢线/信号线)** = DIF 的 EMA9
- **柱(MACD Bar)** = (DIF − DEA) × 2(部分平台不乘 2,看相对变化即可)

> `kline_read.py` 已内置 `macd()` 输出 DIF/DEA/柱与最新交叉/背离状态。

### 3.2 四类信号(按可靠性排序)

1. **零轴穿越**:DIF 上穿零轴=中期动能转多(强于金叉);下穿=转空。零轴上方金叉 > 零轴下方金叉。
2. **金叉/死叉**:DIF 上穿/下穿 DEA。零轴上方金叉=做多加速;零轴下方死叉=做空加速。
3. **柱动能**:红柱(正值)放大=上行动能增强;缩短=衰减(顶背离前兆);绿柱反之。
4. **背离(最重要)**:
   - **顶背离**:价格创新高,MACD(DIF 或柱)未创新高 → 上行动能衰竭,反转预警(顺宏观空时高价值)。
   - **底背离**:价格创新低,MACD 未创新低 → 下行动能衰竭,反弹预警。
   - **隐藏背离(hidden)**:价格回调不破前低(更高低)但 MACD 更低 → 趋势中继(顺势加仓信号),与常规背离方向相反。

### 3.3 缺陷

- 滞后明显(双EMA平滑),拐点晚于价格;震荡市金叉死叉反复(需配合结构/量能)。
- **必须顺趋势用**:在上升通道里,只认底背离/金叉做多,忽略顶背离;下降通道反之。

## 4. RSI(相对强弱指数)

### 4.1 计算与默认

- RSI = 100 − 100/(1 + RS),RS = N 日均涨幅均值 / 日均跌幅均值;默认 **N=14**。
- 取值 0–100,**50 为多空分水岭**。

### 4.2 信号

- **超买/超卖**:>70 超买,<30 超卖(强势趋势中可放宽到 80/20)。注意:**超买不代表马上跌**,强趋势里 RSI 可在超买区钝化数十根。
- **背离**:价格新高但 RSI 未新高(顶背离);价格新低但 RSI 未新低(底背离)——与 MACD 背离同向验证更强。
- **Failure Swing(失败摆动)**:RSI 先跌破 30 又弹回 30 上方=买入失败摆动;先突破 70 又跌回 70 下方=卖出失败摆动(Wilder 经典用法)。
- **50 穿越**:RSI 上穿 50=动能转多,下穿=转空(替代部分均线功能,更快)。

### 4.3 用法纪律

- RSI 是**动量/超买超卖过滤器**,不是方向开关。在下降趋势中"RSI 超卖"是陷阱,必须等宏观/结构转多 + 底背离确认。
- 与 MACD 配合:两者同时底背离=高价值反转预警(但仍需关键位 + 次日确认,见 `ta_reading.md` Morris 框架)。

## 5. 布林带(Bollinger Bands)

### 5.1 构成

- 中轨 = **20SMA**;上轨 = 中轨 + 2×σ(20 日标准差);下轨 = 中轨 − 2×σ。

### 5.2 三种状态与含义

- **收口(Squeeze)**:带宽收窄→波动率收缩,往往是**重大方向突破的前兆**(配合 ATR 收缩验证)。突破方向由宏观/结构决定,不提前赌。
- **喇叭口(Expansion)**:带宽放大→趋势展开,价格沿上轨或下轨"walk"(贴轨运行)=强势。
- **均值回归**:触及下轨且未破=区间买点;触及上轨=卖点(仅适用于震荡/水平通道,趋势中失效)。

### 5.3 与通道/ATR 的关系

布林带本质是"均线 ± 统计波动"的动态通道;在趋势行情中常被价格沿单边"walk",此时改用**趋势线通道**(见 `channels.md`)更贴合。

## 6. 随机指标 / KDJ(摆动指数)

### 6.1 经典随机(Stochastic)

- **%K** = (收盘 − N 日最低) / (N 日最高 − N 日最低) × 100;**%D** = %K 的 3 日平滑。默认 N=14。
- 信号:**超买 >80 / 超卖 <20**;%K 上穿 %D=买入,下穿=卖出;背离用法同 RSI。

### 6.2 KDJ(中国/期货圈常用变体)

- KDJ = 随机指标的本土化:RSV→K(3 日平滑)→D(3 日平滑)→J=3K−2D。
- J>100 超买、J<0 超卖;金叉/死叉/背离用法一致。黄金、原油、A 股联动品种可参考,但**外汇以 MACD/RSI 为主**。

### 6.3 注意

- 随机/KDJ 在强趋势中同样会钝化(长期顶在超买区),与 RSI 同理,必须顺趋势使用。

## 7. 成交量(Volume)与量价

- **放量突破**:突破关键位/通道轨线时伴随成交量放大=真突破概率高。
- **缩量回调**:上升趋势中回调缩量、再起量=健康延续。
- **量价背离**:价格创新高但量能低于均值(见 `kline_read.py` 的 `divergence` 字段)=动能背离预警。
- FX 现货无统一成交量,可**以 tick 量/持仓量/波动率替代**,或用关联市场成交量(如黄金看 COMEX 量、原油看持仓报告)佐证。

## 8. 指标组合实战模板

以"日线定背景、1H 找触发"为例:

| 维度   | 工具           | 背景判定(日线)     | 触发判定(1H,须顺背景)    |
| ---- | ------------ | ------------ | ---------------- |
| 趋势   | EMA20/50/200 | 多头/空头排列      | 价格回踩 EMA20 不破    |
| 动能   | MACD         | 零轴上方/下方、有无背离 | DIF 金叉 DEA、柱由缩转放 |
| 超买超卖 | RSI          | 是否进入极端区      | 背离 / 50 穿越       |
| 波动   | ATR / 布林     | 带宽扩张/收缩      | 止损=1.5–2×ATR     |
| 量能   | 成交量          | 突破是否放量       | 回调是否缩量           |

**收敛规则**:五个维度中≥3 个顺同一方向,且落在关键位/通道轨线,才构成高确定性触发;任一维度反向即降级(参考 `analysis_framework.md` 三维印证)。

## 9. ADX / DMI(方向运动指数 — 测"趋势强度",不测方向)

> Murphy 第 7、10 章。ADX 是**趋势市 / 震荡市的总开关**,比任何单一指标更能决定"该用突破策略还是边界策略"。

### 9.1 构成(默认 14)

- **+DI(上升方向指标)**:衡量多头推进力度(当前高 − 前高 vs 当前低 − 前低 的正向分量)。
- **−DI(下降方向指标)**:衡量空头推进力度。
- **ADX** = |+DI − −DI| / (+DI + −DI) 的平滑值,**只反映趋势"强度",与价格方向无关**。

### 9.2 读法(四档)

| ADX 区间 | 市场状态 | 策略含义 |
|----------|----------|----------|
| **< 20–25** | 无趋势 / 震荡 | 均线、突破策略失效;改用区间边界或离场;指标噪音大 |
| **25–40** | 趋势展开 | 顺势策略有效,可顺 +DI/−DI 方向做 |
| **40–50** | 趋势极强 | 持仓顺向;但 ADX 拐头向下 = 临近 exhaustion,警惕反转 / 回撤 |
| **> 50** | 极端趋势 | 多已运行过半,追单风险高,只持有不新开 |

- **+DI 上穿 −DI** = 趋势转多确认;**−DI 上穿 +DI** = 转空。DI 交叉只给"方向切换",**ADX 给"是否值得做"**。

### 9.3 关键纪律

- ADX 回答"现在有没有趋势、强不强",**不回答方向**;方向由 +DI/−DI 与宏观共同决定。
- **ADX 高 + 宏观多** = 最强顺多背景(配合 EMA 多头排列,见 §1);**ADX 低** = 不做突破,只做边界(水平通道高抛低吸,见 `channels.md`)。
- 与 MACD 配合:ADX>25 上升 + MACD 零轴上方金叉 = 顺势加速的高确定性组合。

## 10. 补充指标(简述,按需启用)

- **OBV(能量潮)**:累计成交量(涨加跌减),验证价格趋势的"量能背书";OBV 与价格背离 = 动能预警。FX 现货无量,可参考关联市场或 tick 量(见 §7)。
- **CCI(顺势指标)**:−100~+100 区间波动,突破 +100 = 强势启动,跌破 −100 = 弱势;对商品(原油 / 黄金)更灵敏,外汇少用。
- **Parabolic SAR(抛物线)**:点随趋势上 / 下移动,价格穿 SAR = 离场信号;适合趋势跟踪止损,但震荡市反复。

> 所有指标输出均为客观事实,方向仍由"宏观定方向、跨市场验方向、盘面定时机"收敛决定。指标只回答"现在动能/波动/超买超卖处于什么状态",不回答"该不该做"。
